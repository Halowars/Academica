# Academica Clipper · desktop Chrome / Edge

1. Unzip the download into a folder you will keep.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on Developer mode.
3. Choose **Load unpacked** and select this folder.
4. Pin Academica Clipper. Open an article, optionally select a passage, and click **Save article & selected text**.
5. Review the import in Academica and choose **Save to this paper**.

The extension only reads a page after you invoke it. It uses activeTab rather than persistent access to all websites. A pending clip is stored locally until accepted. The only destination is `https://halowars.github.io/Academica/`. It does not collect browser history, passwords, cookies, or manuscript text. Saved content follows Academica's existing device/cloud saving choice.

PDFs use **Send this PDF link**, then the app's normal PDF importer. Browser PDF viewers and access-controlled links may require downloading a PDF and importing the file manually. This extension does not bypass publisher access restrictions.
